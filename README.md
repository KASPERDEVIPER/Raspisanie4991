# Расписание группы 4991

Готовая мобильная PWA-страница для GitHub Pages.

## Важно
- 28 сентября 2026 года — **верхняя неделя**.
- Автоматический расчёт использует 31 августа 2026 года как верхнюю неделю и меняет неделю каждые 7 дней.
- Кнопки «Верхняя» и «Нижняя» позволяют проверить расписание вручную.
- Кнопка ↻ возвращает автоматический режим.
- Расписание группы 4991 перенесено из исходного Excel.
- Иконка приложения сделана из предоставленного логотипа.

## GitHub Pages
Загрузите все файлы в репозиторий → Settings → Pages → Deploy from branch → main / root.

На iPhone откройте сайт в Safari → Поделиться → На экран «Домой».


**Недели:** 28.09.2026 — верхняя. Далее автоматическое чередование каждую неделю: верхняя → нижняя → верхняя. На странице доступны две прямые кнопки выбора недели; листать недели не нужно.


**Обновление:** день автоматически выбирается по текущему дню недели; доступны кнопки Пн–Сб для просмотра других дней. Верхняя/нижняя неделя выбирается компактными кнопками. По календарю 28.09.2026 — верхняя, следующая неделя — нижняя, далее чередование автоматически.


Расписание в этой версии взято из предоставленного пользователем script(1).js. Одиночные занятия отнесены к верхней неделе; в параллельных парах первое занятие — верхняя неделя, второе — нижняя. 28.09.2026 — верхняя неделя; далее недели чередуются автоматически.
